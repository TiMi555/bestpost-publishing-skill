# BestPost Publishing Skill

The `SKILL.md` file teaches AI clients how to use BestPost MCP for monitored account/post queries, public media upload, and authorized publishing on Facebook, Instagram, YouTube, and TikTok.

## Install and update

- Download the current skill from [BestPost production](https://app.bestpost.shop/skills/bestpost-publishing/SKILL.md) or [GitHub main](https://raw.githubusercontent.com/TiMi555/bestpost-publishing-skill/main/SKILL.md).
- Save it in your AI client's skills directory as `bestpost-publishing/SKILL.md`, replacing the prior version, then reload the client session.
- BestPost project owners can also use the Settings → AI Tool download link.

The MCP server URL and long-lived project token are configured separately in the AI client. Generate or rotate the token in the BestPost project settings; never put it in this repository.
